# Calculadora de Instalación y montaje

Calculadora estática de instalación y montaje por ítem para presupuestos. Funciona con HTML, CSS y JavaScript, por lo que se puede publicar directamente en GitHub Pages.

## Valores configurados

- Caldera: $250.000 neto.
- Radiador / Secatoalla: $140.000 neto.
- Boiler: $300.000 neto.
- Dificultad / distancia obligatoria por proyecto: $200.000, $300.000, $400.000 o un monto personalizado.
- IVA fijo: 19%.

## Publicar en GitHub Pages

1. Crea un repositorio en GitHub.
2. Sube `index.html`, `styles.css`, `app.js` y `README.md` a la rama principal.
3. En GitHub, entra a `Settings > Pages`.
4. En `Build and deployment`, selecciona `Deploy from a branch`.
5. Elige la rama principal y la carpeta `/root`, y guarda los cambios.

Los tres ítems principales permanecen siempre visibles y parten con cantidad cero. También se pueden agregar extras excepcionales con descripción y precio editables, reiniciar el presupuesto y exportar el detalle a CSV.
